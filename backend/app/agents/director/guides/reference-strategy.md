# Reference strategy

## Start with the shot state

Ask whether one Layout can communicate the composition, blocking, scale, eyelines, handled props, and reveal. Use the smallest compatible reference set that tells the shot's real visual story.

## Add a Layout for a distinct state

Consider another Layout only when it contributes a named distinct state: entrance or visibility, prop handling, spatial reveal, changed blocking or screen direction, or before/after geography. Never infer Layout count from entity count.

## Split when conditioning conflicts

Prefer shot splitting when strict concealment, incompatible compositions, or a large spatial jump makes whole-clip H3 conditioning unreliable. Pictures condition the whole clip, so preserve compatible identity, wardrobe, geography, and object states across the selected set.
